## 🛠️ Yerel Ortamda Testleri Çalıştırma

Exercism CLI veya ilgili dilin geliştirme araçları kullanılarak herhangi bir egzersizin testleri yerel ortamda koşturulabilir:

```bash
# İlgili egzersiz dizinine gidin (Örn: Swift)
cd solutions/swift/<egzersiz-adi>

# Swift birim testlerini çalıştırın
swift test
```
